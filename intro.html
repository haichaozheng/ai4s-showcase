课程简介

面向社科类博士生，用大模型为个人科研项目构建 AI4S 工具栈

课程目标：围绕学生个人科研项目构建 AI4S 工具栈，并应用该工具栈开展科研；进而在 AI 辅助社会科研的方法论层面建立自觉——理解社会计算带来的范式转移，能对自己的 AI 辅助科研过程做方法论审视与论证。每位博士生在 9 周内独立构建覆盖科研全流程的个人工具栈，并以真实科研产出与工具栈仓库作为课程产出。

教学方法

课程采用 Project Based Learning（PBL）——学生在一个真实、有意义的学期项目中主动学习：围绕自己的博士课题，逐步构建覆盖文献→选题→设计→实施→写作全流程的 AI4S 工具栈。方法论优先：工具栈服务于研究方法论，AI 辅助"做对"比"做出来"更重要；每周教学设计围绕"理念—工具—操作—交付成果"四核心咬合推进。

方法论基础：社会计算与经典文献

本课程不止于"会用工具"，更要求学生在 AI 辅助社会科研的方法论层面建立自觉：理解社会计算（以大数据与人工智能算法研究社会、经济与管理）为社会科学带来的范式转移。方法论内容以"核心参考书 + 经典文献"方式随五模块渐进融入——核心参考书为罗家德等《社会计算方法论：社会科学研究的一次范式转移》（清华大学出版社，2026），其主线"理论、数据挖掘与建模的三角对话"正是本课程的人机交互姿态；Lazer (2009/2020)、Argyle (2023) 等经典文献随周次渐进安排（见每周材料）。

AI4S 工具栈五模块

工具栈按社科科研全流程组织为五个模块，大模型在每个模块中既是工具也是"研究伙伴"：文献智能（检索→阅读→综述）、研究选题与假设构建（多智能体 gap 分析与假设候选生成流水线，Co-Scientist 式"生成→反方批评→人工筛选"，产出带证据锚点的 Gap 证据表）、研究设计（方法审计配置与"生成→审计→裁决→定稿"循环）、研究实施（数据三路径 + StatsPAI agent-native 计量 + Mesa/Mesa-LLM 智能体仿真）、论文写作（写作-审计双 Agent，生成与核验分离），并有 AI 系统评估嵌入研究实施各步作为质量保障；W8 用 LangGraph 把多智能体升级为严肃实现的科研智能体系统。

共同 AI 基础工具栈

六项 AI 基础能力随科研流程渐进式融入，而非单独设课：Prompt Engineering 与 AI 辅助编程（opencode/cursor，W7 增补 DeepSeek Harness 形成双 harness 对比）W1 起步 → RAG W3 文献综述 → Agent W4-W5 gap 分析与假设候选生成多智能体、研究设计生成-审计多智能体，W6-W7 延续（调研数据生成/分析），W8 LangGraph 科研智能体设计，W9 写作-审计双 Agent → Skill W6-7 研究实施、W9 论文评审 → AI 系统评估 W7 质量控制、嵌入各步验证。大模型贯穿全程，作为工具栈的核心支撑。

跨学科适配

学生背景横跨经济学、计算机科学、管理学、金融等。工具栈围绕个人研究方向定制，兼顾定量（计量/统计/数据挖掘）与定性（文本/案例）研究范式——无论因果推断还是质性编码，都能在 AI 赋能下找到自己的工具组合。

公开产出为终点

课程以 AI4S 工具栈仓库 + 科研产出为终点：学期末每人提交个人工具栈仓库与论文成果。完整 9 周安排详见项目之旅。

评分结构一览

总评 = 平时 50% + 期末 50%。平时：出勤与课堂参与 10%（9 周出勤 + 讨论参与度）+ 阶段成果一：研究选题与研究设计（含文献综述）25%（W5，检索工具列表 + RAG 知识库 + 综述文稿 + gap 多智能体分析 + 研究问题陈述 + 假设候选清单 + 研究设计方案）+ 阶段成果二：个人科研工具栈汇总 15%（W8，覆盖文献检索、综述、空缺识别、假设构建、方法设计等环节的工具栈，其中至少 2 个为自设计工具并给出 GitHub 项目库）。期末：个人科研报告 50%（W9，论文初稿 + 终稿 + 引用核验报告 + AI 使用声明 + 论文评审 skill + 工具栈仓库 + 反思报告，含个人 AI4S 方法论框架重构图）。文献综述不单独计分，作为 gap 分析语料输入计入阶段成果一。
