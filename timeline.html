项目之旅

9 周 · 4 个阶段 · 从个人科研痛点到工具栈与论文产出

1
Foundation · 工具准备 + 文献检索与综述 W1 – W3

核心挑战：如何让 AI 工具栈与个人科研的真实痛点对齐，并以方法论自觉完成文献检索与综述的 AI 冷启动？

  • W1 工具准备 — AI 工作环境搭建：AI4S 范式与人机交互姿态（人判断、AI 执行）、政策依据（国发〔2025〕11 号）；三段式课堂——Streamlit 案例预演（12.4 万条股吧评论上词典法 vs LLM 法）→ 环境演示 → Prompt 驱动关键词脚本 → 交付工具环境就绪（六步验收截图）+ 第一个 Prompt 驱动脚本跑通 + 最简版 AGENTS.md（W3 检查） 本周材料 →
  • W2 文献检索 — 检索工具与策略：检索即方法论（PRISMA 流程、检索式、纳入排除标准）；学术 API 批量获取文献元数据、AI 辅助初筛 → 交付文献检索工具列表 + 原始文献库 本周材料 →
  • W3 文献综述 — RAG 知识库 + AI 综述：RAG 改变文献管理范式（从"读完记住"到"检索即用"）；构建个人文献知识库、AI 辅助综述生成 → 交付文献综述（知识库 + 综述文稿 + 反思日志，计入阶段成果一） 本周材料 → 综述初稿
2
Design · 选题 + 研究设计 W4 – W5

核心挑战：如何把"发现空白"升级为有证据锚点、可核验、可审计的流水线，并让方法选择成为研究者的核心判断？

  • W4 发现空白→凝练问题→生成假设候选 — gap 分析与假设候选生成多智能体：1 个主 Agent 编排 + 7 个子智能体协作（抽取→标注→核验→侦察→凝练→生成假设候选），Audit Scribe 全程留痕；假设候选按 Co-Scientist 式流程生成（AI 出候选与反方批评，逐条人工筛选修订）→ 交付研究问题陈述（含 Gap 证据表与协变量结构）+ 假设候选清单 本周材料 →
  • W5 研究设计 — 方法审计配置：五层五角色设计-审计架构，"生成草案→审计追问→学生裁决→定稿"循环；不教"所有方法"，而是构建可被智能体加载、可随研究修订的方法审计配置 → 交付研究设计方案（逐字段带依据、置信度标注、修订痕迹） 本周材料 → 设计方案
3
Implementation · 研究实施：数据集 · 实证 · 仿真 · 智能体设计 W6 – W8

核心挑战：数据从哪来、结论可信吗？三路径数据 + agent-native 计量 + LLM 智能体仿真，质量控制嵌入每一步验证。

  • W6 研究实施 — 数据集 + 实证（StatsPAI）：数据来源三路径（第三方数据集 / 自采实验 / 智能体辅助生成类人数据，选择即方法论判断）；用 StatsPAI 实施回归 / DID / IV / DML 等实证估计并导出出版级表格 → 交付数据集（含路径选择说明）+ 实证结果 + 数据 Skill 本周材料 →
  • W7 研究实施 — 仿真（DeepSeek Harness + Mesa + LLM 智能体）：先跑通规则驱动 Mesa 基线模型，再用 Mesa-LLM 把 LLM 嵌入智能体决策并记录每一次调用；引入第二编程智能体 harness（dsh）与 opencode 形成双 harness 对比；稳健性检验与 AI 系统评估 → 交付研究实施结果（基线模型 + 仿真结果 + LLM 调用日志 + 验证报告 + 分析 Skill） 本周材料 → 评估报告
  • W8 大模型智能体设计 — 基于 LangGraph：把 W4-W7 的"prompt 纪律拼装角色"升级为用框架严肃实现的智能体系统——显式共享状态、可控流程、checkpointer 持久化、关键节点人工断点（interrupt）；断点设在"人判断"处 → 交付科研智能体设计方案 + 运行记录 + 阶段反思日志；同时提交个人科研工具栈汇总（阶段成果二，含 2 个自设计工具） 本周材料 → 工具栈汇总
4
Writing & Integration · 论文写作 + 整合展示 W9

核心挑战：如何把过程沉淀为论文与可复用的工具栈，生成与核验分离、引用可回溯，并经同侪检验公开展示？

  • W9 论文写作 — 起草 · 评审 · 修订 · 展示（期末）：写作-审计双 Agent 起草（生成与核验分离、引用可回溯 Zotero/DOI）、论文评审 skill 五维模拟评审、同侪互评修订、AI 使用声明对照 W1-W8 审计记录、工具栈最终整合与公开展示 → 交付论文初稿 + 终稿 + 引用核验报告 + 工具栈仓库 + 反思报告（期末 50%） 本周材料 → 公开展示
