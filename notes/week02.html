W2 · 第1节 · OPENING

开场：检索是方法论，不是"搜一下"

  • 本周定位：Phase 1 Foundation 第 2 周——文献检索是方法论（检索式、纳入排除标准、留痕可复现），不是"搜一下"
  • 本周主线：AI 辅助筛选，但人来定标准；文献检索正是"AI 执行、人定标准"的第一个真实科研环节
  • 与 W1 的衔接：本周是 W1 AI 辅助编程的第一次真实科研应用——用 opencode 开发结构化检索脚本
学习目标：说明系统性检索策略（检索词 / 数据库 / 纳入排除标准）→ 用 opencode 开发检索脚本并与 AI 结对调试 → 用课程 skill 三源批量获取文献元数据 → 说明 AI 辅助筛选的边界与检索可复现意识。
W2 · 第1节 · 必读分享（8 分钟）

💡 Can Generative AI improve social science?

  • W1 课后必读：Bail, C. A. (2024) "Can Generative AI improve social science?" PNAS, 121(21), e2314021121（开放获取）
  • 💡 抽取 2–3 位同学分享读后感想：生成式 AI 能改进社科研究的哪些环节——调研、实验、自动化内容分析、ABM？
  • 局限在哪：训练数据偏见、伦理、可复现性、"低质研究"泛滥
  • 与"人判断、AI 执行"如何呼应？教师收拢到本周主线：文献检索正是这个分工的第一个真实科研环节
W2 · 第1节 · 方法论 · 检索式构建（20 分钟讲解含现场演示）

Levy & Ellis「Inputs」之一：检索式构建

  • 以 Levy & Ellis (2006) "输入—加工—输出"系统框架的 §2 Literature Review: Inputs（文献获取与筛选）一节为纲，讲三组要点
  • 检索式构建（原文 "Keywords search"）：检索词作用于标题 / 摘要 / 关键词字段
  • 新手"冷启动"难题——检索词从哪来？最佳来源是文献本身：ACM 分类体系、MIS Quarterly Roadmap 可作起点
  • 关键词有生命周期（MRP→ERP）、技术热词（如 phishing）易失效——应上升到稳定的理论构念
  • 关键词检索只是起点，需配合回溯检索（backward，查参考文献）与前向检索（forward，查施引文献）——源自 Webster & Watson (2002)
W2 · 第1节 · 方法论 · 数据库选择 + 纳入排除标准

Levy & Ellis「Inputs」之二、之三

  • 数据库选择（原文 "Where to look for quality IS literature"）：
    • 同行评审权威期刊应为主体，非评审 / 从业者来源仅限事实性信息
    • 用期刊排名列表（ISWorld）反推数据库覆盖（原文 Figure 2 将排名期刊映射到 ProQuest / ScienceDirect / IEEE Xplore / ACM DL 等库）
    • 勿把检索范围锁死在单一数据库
  • 纳入排除标准（原文 "Testing for applicability"）：
    • 适用性检验含纳入 / 排除与文献伦理使用两个面向
    • 检索命中过多时（原文以 TAM 海量文献为例）依据什么纳入、排除须事先定标准
    • 守住质量底线：同行评审优先
检索的价值：Webster & Watson（2002）"分析过去、准备未来"——检索质量决定综述上限。现场演示：从大家提的一个真实关键词出发，走完"关键词检索 → 回溯（查参考文献）→ 前向（查施引文献）"的完整链条。
W2 · 第1节 · 工具盘点 + 课堂互动（9 + 8 分钟）

检索工具盘点 · 你的检索经验

  • 检索数据库：Google Scholar / Web of Science / Semantic Scholar / Crossref / arXiv
  • 第三方文献平台：AMiner；个人文献管理数据库：Zotero（W3 主角）
  • 课堂实操范围：只覆盖 arXiv / Google Scholar / Web of Science 三源（整合为课程 skill search-paper-ai4s-class），不做知网 / CNKI，中文文献课后自查
  • ✍️ 检索式初稿（3 min）：每人草拟自己领域的检索式
  • 💡 经验分享（5 min）：抽 2–3 位同学分享平时检索文献的真实经验——关键词及同义词怎么积累、惯用哪些数据库 / 平台、踩过什么坑（只用技术热词、只查一个库）；教师把分享对号入座到 Inputs 三要点
过渡：检索式有了，下一节把它写成脚本——"把检索式写成脚本"是本周方法论落地的关键一步。
W2 · 第2节 · 微实验 1（8 分钟 · 师生共建）

opencode 开发检索脚本 · 最小调用

  • 开场点明检索脚本需要的结构：检索式参数化、API 调用、分页与限流、异常处理
  • 每个实验都是：提任务 → 对话式生成 → 点运行 → 看结果，教师边做学生边跟
  • 微实验 1：让 opencode 写最小脚本——调用 arXiv 开放 API（免 key、返回 XML）检索一个关键词，解析并打印前 5 条论文标题
  • 体验"API 调用 + 异常处理"最小闭环
学生操作文档：materials/week02/opencode-search-lab.md（MD 下载），含提示词模板与排错速查；环境没配好先看 venv-setup.md（MD 下载）。
W2 · 第2节 · 微实验 2（12 分钟）

换库与边界：三源对比 · 工具可得性

  • 微实验 2：同款脚本改 API 端点与参数，切换到 Google Scholar（SerpAPI Key）与 Web of Science（机构 Key）
  • 结果写入带留痕列（query / source / retrieved_at）的 CSV，同一检索式对比三源覆盖差异：arXiv 只有预印本、GS 有被引数与灰色文献、WoS 是 SSCI/SCI 正式库
  • 工具边界：Web of Science 需机构订阅 Clarivate API key
呼应 Inputs："勿锁死单一数据库"——工具边界本身就是检索策略的一部分。
W2 · 第2节 · 跟做 + 留痕（15 + 10 分钟）

结对调试 · 检索留痕意识

  • 学生跟做（15 min）：每人用课程 skill search-paper-ai4s-class 把检索式换成自己领域，用三源中可用的源跑通拿到第一批元数据
    • arXiv 适合 CS / 量化方向，社科方向多用 scholar / wos
    • 缺 Key 时先跑 arxiv，课后申请 Key 补全
    • 报错按"问 AI（附报错）→ 同学互助 → 举手教师"顺序排障
  • 检索留痕意识（10 min）：检索式、数据库、日期、命中数——每次检索可复现，为 W3 清洗与综述写作留证据
  • 留痕字段就写进 CSV 的列名里（query、source、retrieved_at）——让"可复现"从口号变成脚本的一部分
W2 · 第3节 · SKILL 基础（12 分钟 · 教师讲解为主）

为什么需要 skill · skill 的解剖

  • 升级链条：一次性脚本 → 参数化脚本 → skill
    • 脚本跑完就沉底，每次让 AI 重写都得重新交代流程
    • skill 把"什么时候用、怎么用、有哪些约定"写进 SKILL.md，opencode 在对话中自动触发、跨项目复用——把个人检索经验固化成可复用资产
  • skill 的解剖（以课程 skill search-paper-ai4s-class 为活教材）：
    • frontmatter 的 name / description 决定"何时被触发"（description 要写清使用场景与触发关键词）
    • 正文写工作流程、默认命令、参数表；scripts/ 放脚本、references/ 放 API 文档摘录
    • 边界写进 skill 本身（如"人定纳入排除标准，本 skill 只检索与去重"）——工具设计就是方法论落地
落点："AI 执行、人定标准"从口号变成规则——写进 skill 的边界条款里。
W2 · 第3节 · 从头构建 skill（18 分钟 · 师生共建微实验）

用 skill-creator 构建多源检索 skill

  • 原料：第 2 节自己写的三个脚本；第 2 节没写全的同学，直接以课程 skill 为案例拆解重建
  • 构建流程四步：
    • ① 定边界（做什么 / 不做什么）
    • ② 让 opencode 起草 SKILL.md，人修改 description 的触发词与场景
    • ③ 收编脚本进 scripts/
    • ④ 实测：对 opencode 说"帮我检索文献"看是否自动触发；用自己构建的 skill 对同一检索式分别查 arXiv / Google Scholar / Web of Science，比较覆盖与被引数差异、标记去重字段（DOI → arXiv ID → 规范化题名）
学生操作文档：materials/week02/skill-lab.md（MD 下载），含提示词模板与验收检查点。
W2 · 第3节 · 质检 + 初筛 + 铺垫（7 + 8 分钟）

skill 质检 · AI 辅助初筛 · W3 预告

  • skill 质检与改进（7 min）：AI 产品也有"同行评审"——用 skill-quality-reviewer 给自己的 skill 体检（description 质量、结构完整性、写作风格），用 skill-improver 把改进建议落地；同座位互换，互相测对方 skill 的触发准确度；落选的表述、冗余的说明就在这一轮删掉
  • AI 辅助初筛（8 min）：人定纳入排除标准 → AI 按标准对元数据（标题 / 摘要）做初步筛选分类 → 抽查校准；边界：AI 执行筛选，人来定标准
  • 文献库不足 ≥20 篇的课后用自己构建的 skill 补全
  • W3 预告：把原始文献库导入 Zotero 清洗、用两篇方法论文献指导综述写作；预告进阶轨（手写最小 RAG，加分）
