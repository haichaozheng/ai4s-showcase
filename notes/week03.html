授课要点 · 文献综述 — RAG 知识库 + AI 综述

第 3 周课堂内容纲要（3 节课）· 第 1 节文献库整理与 Zotero MCP 直连 · 第 2 节综述写作规范与最小 RAG 实操 · 第 3 节设计人在环路的 AI 辅助综述生成 skill。点击「翻页模式」可像 PPT 一样逐页投影（键盘 ← → 翻页，F 全屏）；默认滚动模式适合课后复习。

W3 · 第1节 · OPENING

开场：从检索到综述的桥梁

  • 本周定位：Phase 1 Foundation 第 3 周，文献综述（计入阶段成果一）。文献库整理是检索到综述的桥梁
  • 范式转变：第三方智能检索工具改变文献阅读范式——从"读完记住"到"检索即用"
  • 核心立场：综述是结构化综合而非摘抄堆砌；AI 执行机械活，人在闸口做判断
  • 与 W2 的衔接：上周检索得到的 ≥20 篇文献池，本周导入 Zotero 清洗，进而驱动综述生成
学习目标：用 Zotero 管理文献库（导入、去重、标签、规范化、纳入排除筛选）→ 课堂跟做跑通最小 RAG（切分→嵌入→存库→检索）→ 用 Zotero MCP 做智能检索与问答 → 设计并实现人在环路的 AI 辅助综述生成 skill。
W3 · 第1节 · 文献库整理（12 分钟）

文献库整理与去重：构造参考文献池

  • 目标不是"管理文献"，而是构造后续生成工作流的参考文献池
  • AI 查重（只读）：无专用查重工具——AI 拉全库按标题 / DOI 分组输出疑似重复
  • 人工合并：回 Zotero 界面 Duplicate Items 视图，核对哪份带 PDF 和标注再合并
  • 批量打标签：先 1 篇试水，再 zotero_batch_update 批量
学生操作文档：materials/week03/zotero-lab.md（MD 下载）第 6 步——课前须完成 Zotero MCP 安装与 OpenCode 配置（第1–3步）和写入授权（6.1 节，弹窗选 Always Allow）。
W3 · 第1节 · 纳入排除（8 分钟）

纳入排除标准：Zotero 管"信什么"

  • 用 zotero_advanced_search 按 dateAdded 圈出 W2 导入批次，再按时间范围、方法论类型筛选
  • 分工点明：Zotero 管"信什么"（人工守住的 screening 环节），AI 工作流管"怎么写"
  • 这是 W2 Levy & Ellis"输入—加工—输出"框架中 Inputs 环节的延续：纳入排除标准事先定好，不是边看边扔
呼应 W2：W2 检索阶段定下的纳入排除标准（同行评审优先、勿锁死单一数据库），本周在生成工作流中落地为文献池的边界。
W3 · 第1节 · MCP 直连（18 分钟）

MCP 直连：找→读→标注 · 语义检索埋点

  • 验证连接（/mcps 里 zotero 显示 connected）后走完整流水线：关键词检索 → 读元数据与摘要 → 全文与续读 → 高亮标注提取
  • 子串匹配三规则：多词收窄、默认只搜元数据、没命中自动降级
  • 提及 AMiner 等第三方智能检索工具（学者图谱、对话式检索）作为对照路线，不展开演示
  • 末尾 2 分钟语义检索初尝（zotero_semantic_search）——为第 2 节 RAG 埋点
  • 💡 课堂互动：请 1 位同学投屏用自然语言操作自己的文献库
学生操作文档：materials/week03/zotero-lab.md（MD 下载）第 4–5 步——MCP 直连的完整流水线。
W3 · 第2节 · 综述写作规范（10 分钟）

综述有逻辑框架，而非逐篇罗列

  • 逻辑框架：按主题 / 方法论 / 时间线组织文献，而非"作者 A 说了什么、作者 B 说了什么"的罗列
  • 好综述与差综述对比：概念组织 vs 逐篇摘抄——差综述是"文献列表的散文版"
  • 以 Webster & Watson（2002）"概念中心矩阵"说明如何按概念而非按篇组织文献：行=概念，列=文献，一眼看出概念间关系与研究空白
  • W2 检索阶段的方法论阅读（Levy & Ellis 2006、Webster & Watson 2002）在综述写作阶段的延续——也是第 3 节大纲闸口的方法论前置
落点：综述的"组织逻辑"就是第 3 节 skill 设计里 G-大纲闸口要人裁决的核心判断。
W3 · 第2节 · RAG 原理（8 分钟）

从"读完记住"到"检索即用"

  • RAG 概念讲解：检索（Retrieval）→ 增强（Augmentation）→ 生成（Generation）——先把相关片段找出来塞进 Prompt，再让 LLM 基于片段回答
  • 衔接第 1 节末尾体验的 zotero_semantic_search——它就是 RAG 检索环节的自动化封装
  • 以 LiRA（AAAI 2026）为实例：其 Subsection Writer 用 FAISS 按小节检索文献、引用完整标题作"语义锚点"抑制幻觉
  • 为什么检索是核心瓶颈：检索不到，再强的 LLM 也编不出靠谱答案——生成质量的上限由检索质量决定
W3 · 第2节 · 最小 RAG 跟做（22 分钟）

跑通 rag_demo.py：手写一遍检索

  • 按 RAG-lab.md 第 3–5 步全员跑通 rag_demo.py——嵌入存库 → 交互式语义检索
  • 默认问题："数字技术加剧了什么样的不平等？"——体会字面无关仍可命中（问句里没有"数字鸿沟"四个字，语义检索照样找到）
  • 换自己的问题连续检索（回车用默认问题、再回车退出）
  • 字面包含对比：同场看清语义检索与关键词检索的差异
  • 课前已装依赖、模型已分发，课上零下载——跑通即完成"检索是核心瓶颈"的体感
  • 💡 课堂互动：抽 1–2 位投屏演示自己的检索问题与结果对比
学生操作文档：materials/week03/RAG-lab.md（MD 下载）——进阶路线（Streamlit 检索测试台 / 换中文嵌入模型 / 接入 LLM）为加分项，课后任选。
W3 · 第2节 · 对比与小结（5 分钟）

三条检索路线对比

  • 谁在检索、检索什么——同是"检索"，三种实现路线：
  • ① MCP 直连（第 1 节）：Zotero AI 实时检索原库，关键词 + 语义
  • ② 手写 RAG（刚跑的 demo）：预先嵌入再语义检索——每一步都是自己搭的
  • ③ LiRA 的 FAISS 小节级检索：生成时按小节检索，引用 ≤文献池 25%
  • 小结：从理解 RAG 到 AI 辅助综述生成的过渡——第 3 节把这三条路线组装成你自己的综述生成工作流
W3 · 第3节 · 工作流设计（10 分钟）

拆解综述写作流程：LiRA 对照

  • 先自己拆：综述写作流程拆解为子任务（检索→筛选→提取→组织→生成→审查），明确每步的输入输出与知识库配置
  • 为每个子任务标注"AI 可自动 / 必须人裁决"——再对照 LiRA 四智能体参考架构
  • LiRA（AAAI 2026）四智能体：Outline Drafter 大纲起草 → Subsection Writer 分节写作 → Editor 润色（不改事实）→ Reviewer 四准则质量审查（最多 3 轮）
  • 关键提问：LiRA 把哪些判断自动化了（Reviewer 循环自动跑、引用自动核查）？课堂版为什么要把这些裁决权拿回来？
判断标准：机械转换（格式化、润色、按模板提取）可自动；涉及研究判断（信什么文献、按什么逻辑组织、引用是否成立、终稿是否合格）必须人做。
W3 · 第3节 · 智能检索实操（15 分钟）

个人文献库智能检索实操

  • 每人用自己的文献库，用 Zotero MCP 直连检索（第 1 节已配好）：关键词检索零门槛，装了 [semantic] 的可用语义检索
  • 提取综述所需的关键信息：研究问题 | 理论框架 | 方法 | 核心发现 | 局限
  • 体会两种检索的差异：精确匹配 vs 按意思找——同时为你的 skill 验证检索底座（哪些检索词有效、语义检索质量如何）
  • 💡 课堂互动：抽取 2–3 位同学投屏演示智能检索过程，全班交流检索策略与效果（3–4 分钟）
学生操作文档：materials/week03/review-gen-lab.md（MD 下载）第 2 步——完整步骤见"设计参考"。
W3 · 第3节 · skill 骨架搭建（15 分钟）

人在环路的 review-gen skill：骨架与试跑

  • 把工作流设计落成 .opencode/skills/ 下的 skill 骨架：阶段划分、人工闸口位置、各阶段规程要点与输出文件约定（review/ 目录 + memory/decisions.md 留痕）
  • 最少 3 个闸口：G-纳入（文献池清单审查）· G-大纲（候选大纲裁决，通常最重）· G-终审（接受本轮还是再来一轮）；建议加 G-引用（抽 3 条引用核对，防幻觉训练点）
  • 检索层约定调用 Zotero MCP（关键词 + 语义检索），明确每阶段用哪种检索、检索什么
  • 课堂只做设计 + 骨架，实现全部课后完成；课堂内做一次单节试跑演练——用一段 Prompt 走通"检索→提取→写一节"，这段实测就是你的 Subsection Writer 提示词原型
  • 💡 课堂互动：抽 2–3 位投屏讲自己的闸口设计——闸口放在哪、为什么
学生操作文档：materials/week03/review-gen-lab.md（MD 下载）——闸口设计、防幻觉引用核查、留痕要点清单；课堂不给参考实现，教师参考实现 W4 学生分享后发布。
W3 · 第3节 · 阶段收束（5 分钟）

Phase 1 完成 · 课后务必完成

  • Phase 1（Foundation）完成：回顾文献智能模块——检索（W2）→ 整理与综述（W3）→ AI 工作环境（W1）三周闭环
  • 课后务必完成：完成 review-gen skill 实现，并用它生成个人选题方向的文献综述初稿——跑通完整工作流（检索→筛选→提取→组织→生成→审查），第二轮起对 OpenCode 说"修改综述：<反馈>"迭代打磨
  • ⚠️ W4 课堂将随机抽取 2–3 位同学分享自设计的 skill 与综述成果——这份综述同时是 W4 gap 分析的语料输入，认真做直接服务于下周的选题
  • 教师参考实现将在 W4 学生分享后发布供对照——先有自己的设计，再对照差距，学习效果远好于先看答案
  • 预告 Phase 2：选题 + 研究设计（W4–W5）
