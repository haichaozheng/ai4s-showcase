开源即教材

每个成熟开源项目都是一节现成的 AI4S 大师课：同样的科研环节，顶级团队是怎么做的。读 README、跑代码、拆 Prompt，比任何教程都更快学到工具栈设计。

本页收录通用的开源 AI4S 项目供学习参照；同学们的个人工具栈将在学期末课程展示中另行呈现。

文献智能 · 检索→阅读→综述

PaperQA 2
开源
Future House · AI 科研加速机构
面向科学文献的高精度 Agentic RAG 问答引擎：多轮"检索→评估→引用"，写出带引文的研究综述。在文献综合任务上达到超越领域专家的表现——"文献智能"模块的技术天花板参照。
RAG 文献问答 Python
GitHub 论文
OpenScholar
开源
Ai2 艾伦人工智能研究所 · 华盛顿大学
开放的科学文献综合模型：以 4500 万篇开放获取论文为数据底座，引文感知生成 + 自我反馈迭代，成果发表于 Nature。模型、数据、检索索引全部开放，是"开放科学 + AI4S"路线的标杆。
文献综合 开放模型 Nature
GitHub 在线演示 论文

研究选题 · 发现空白→凝练问题

The AI Scientist
开源
Sakana AI
端到端自动化科研系统：从 idea 生成、实验设计、代码执行到论文撰写与自动评审全流程。它是"AI 能否做科研"的前沿实验——重点看它如何设计选题与全流程编排，而非替代人。
自动化科研 Idea 生成 Agent

研究设计 · 方法选择→框架搭建

DoWhy
开源
PyWhy 社区 · 微软发起
因果推断框架：把因果分析组织为"建模→识别→估计→反驳"四步可审计工作流，每一步都可检验、可反驳。社科因果研究设计的可靠底座，也是"方法论优先"的典范工程。
因果推断 研究设计 Python
GitHub 文档

研究方案实施 · 数据采集→编码分析

EconML
开源
PyWhy 社区 · 微软发起
面向异质性处理效应（CATE）的机器学习库：Double Machine Learning、因果森林、深度工具变量等方法集于一身，经济与政策评估研究的主流工具。看它如何在代码层面界定"方法的适用边界"。
因果机器学习 政策评估 计量
GitHub
LLooM
开源
斯坦福大学 HCI 组
AI 辅助定性分析工具：LLM 驱动的"概念归纳"从大规模非结构化文本中自动提炼可解释的高层概念，支持类似人工质性编码的迭代分析循环（CHI 2024）。定性研究 AI 赋能的代表作品。
定性编码 概念归纳 CHI 2024

论文写作 · 结构规划→撰写修订

STORM
开源
斯坦福大学 OVAL 组
开源知识整理引擎：像撰写百科条目一样，通过多视角提问与多源检索，生成带完整引用的结构化长文。可直接作为文献综述与背景章节初稿的生成器，也是"检索增强写作"的教科书实现。
长文写作 知识整理 RAG
